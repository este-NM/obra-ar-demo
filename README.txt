DEMO WEBAR CON RECONOCIMIENTO AUTOMÁTICO DEL PRINT

Contenido:
- index.html: experiencia WebAR
- target.jpg: imagen objetivo usada para reconocer el print
- traces.png: trazas luminosas selectivas
- glow.png: halo suave de esas trazas

PARA ACTUALIZAR EL REPOSITORIO DE GITHUB
1. En tu repositorio obra-ar-demo, eliminá o reemplazá el index.html anterior.
2. Subí los cuatro archivos de esta carpeta a la raíz del repositorio.
3. Hacé Commit changes.
4. Esperá entre 1 y 3 minutos y recargá tu enlace de GitHub Pages.
5. En el iPhone, cerrá la pestaña anterior o recargala sin caché.

USO
- La primera visita prepara el reconocimiento de la obra y puede tardar algunos segundos.
- Después se guarda una copia local en el navegador para acelerar siguientes visitas.
- Tocá Activar cámara.
- Apuntá al print completo, de frente y con iluminación uniforme.
- No aparece ninguna copia transparente de la obra: sólo las trazas dinámicas, y únicamente al reconocer el print.
- Tocá sobre el print en pantalla para producir una propagación por las trazas.

NOTA
Este demo compila el target en el propio navegador durante la primera visita para evitar un paso manual con un archivo .mind. Para una versión final de cliente conviene precompilar targets.mind y dejar la experiencia inmediatamente lista.
