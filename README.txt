DEMO WEB CON CÁMARA — INSTRUCCIONES

Este archivo no debe abrirse como documento local en iPhone, porque la cámara web requiere una página servida mediante HTTPS.

Forma más simple:
1. En una Mac o PC, descomprimir esta carpeta.
2. Subir la carpeta completa a un hosting estático HTTPS (por ejemplo, Netlify Drop, Vercel o GitHub Pages).
3. Abrir en el iPhone la dirección HTTPS generada.
4. Pulsar “Activar cámara” y aceptar el permiso.
5. Apuntar al print.
6. Alinear el overlay: un dedo mueve; dos dedos escalan y rotan.
7. Pulsar “Ocultar guía”.
8. Tocar sobre la obra para generar una propagación luminosa.

El prototipo actual usa alineación manual; todavía no reconoce automáticamente el print.
